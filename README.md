# Smart Greenhouse Enterprise: Digital Twin Simulation
Industrial-grade environmental simulation for Reinforcement Learning research. 
Developed with FastAPI, Gradio 6.0, and Docker.

## Quick Start
1. **Manual Control:** Use the Slate & Emerald dashboard to adjust parameters.
2. **Telemetry:** Monitor real-time charts and cumulative reward progression.
3. **API Access:** Machine-readable JSON state objects available for RL agents.
