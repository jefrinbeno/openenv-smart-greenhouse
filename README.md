# 🌿 Smart Greenhouse Enterprise: Digital Twin Simulation

An industrial-grade environmental simulation designed for Reinforcement Learning research. 
This project integrates a **FastAPI** backend with a **Gradio 6.0** professional dashboard.

## 🏗️ Architecture Overview
* **Engine:** Differential physics-based greenhouse simulation.
* **Interface:** Enterprise-grade "Slate & Emerald" telemetry dashboard.
* **API:** Machine-readable JSON state objects for RL agent integration.
* **Deployment:** Containerized via Docker and synced through GitHub Actions.

## 📊 Key Features
* **Live Analytics:** Real-time thermal and moisture trend charting.
* **Economic Telemetry:** Cumulative reward progression tracking.
* **Audit Logs:** Full historical step-by-step data export.
